# Student Course Management System

A console-based Student Course Management System developed using Java, JDBC, Maven, and PostgreSQL.

## Technologies Used

- Java 21
- JDBC
- Maven
- PostgreSQL
- HikariCP
- IntelliJ IDEA

## Features

### Student Management
- Add Student
- Update Student
- Delete Student
- View All Students

### Course Management
- Add Course
- Update Course
- Delete Course
- View All Courses

### Enrollment Management
- Add Enrollment
- Update Grade
- Delete Enrollment
- View Student Enrollments

## JDBC Concepts Implemented

- JDBC Driver Management
- Database Connection
- Statement
- PreparedStatement
- CallableStatement
- ResultSet
- Batch Processing
- Stored Procedure
- Stored Function
- Transactions
- Savepoints
- Connection Pooling
- DatabaseMetaData
- ResultSetMetaData
